# Notebooks

Keep study notebooks numbered in learning order, for example `01_end_to_end_ml.ipynb`.
Each notebook should state its question, experiment, result, and conclusion.

- `ch01_ml_landscape.md`: machine learning landscape notes
- `02_end_to_end_ml.ipynb` and `ch02_end_to_end_ml_project.md`: California housing workflow
- `ch03_classification.md`: classification concepts and evaluation notes
- `04_training_models.ipynb` and `ch04_training_models.md`: training models, optimization, regularization, and classification probabilities
